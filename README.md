# 赴约：可安装的手机端 PWA

运行 `node preview.cjs` 后访问 http://localhost:8765。本地预览服务器仅监听本机。Service Worker 不会在直接双击 `index.html` 时启用。

## PWA

- 包含 Web App Manifest、主屏图标、独立显示模式和离线缓存。
- iPhone 使用 Safari 的“分享 → 添加到主屏幕”安装。安装入口会在页面中显示操作提示。
- PWA 必须通过 HTTPS 发布；`localhost` 仅用于本机开发。
- 当前数据保存在安装该 PWA 的设备中。支持把记录、照片和背景导出为 JSON 备份，再导入恢复。

## 1.0 功能

- 关注艺人的添加、重命名和删除。
- 现场记录的新建、编辑、删除、状态管理与自动次数统计。
- 行政区足迹地图、城市点亮、缩放和当地记录查看。
- 城市名称自动识别，以及覆盖全国 34 个省级区域的“省份—地级市及同级行政区”两级选择；港澳台包含在内。
- 自定义背景持久保存，现场照片及票根在本机压缩保存。
- 订单截图通过 Tesseract.js 在浏览器端识别，识别后由用户核对字段。
- 应用内图片、票根、背景和文字记录合计采用 300 MB 软上限；达到 270 MB 时预警，达到上限后暂停新增图片并打开清理面板。
- 清理面板支持按照片、票根或全部内容选择删除，文字记录不会被自动清除。

## 本轮更新

- 城市足迹使用本地省级行政区 GeoJSON 底图，支持全国、足迹区域两种视野。
- 仅已到场活动点亮城市；城市按钮可切换当地现场记录。未包含坐标的城市保留记录并提示待定位。
- 手机优先布局：安全区留白、底部导航、横向艺人卡片、底部表单、16px 输入字号、城市按钮至少 44px 高。
- 浏览器中检查了 320px、390px 窄屏地图和 320px 表单，未发现页面横向溢出。尚未进行真实 iPhone Safari 或微信真机测试。

## 图片导入优化（2026-10-22）

- 本地 OCR 支持订单/海报类型、简繁体语言选择、可关闭的对比度增强和识别补充说明。
- 提取结果先核对再应用，默认仅填写空栏；原图是否作为票根/照片保存由用户选择。
- 日期支持多场次、补全年份与说明筛选；新增记录可分别保存多个日期，编辑已有记录仅支持单日。
- 场馆按标签和候选提取，部分明确后缀错字整理后显示提示；不承诺花体字、模糊图片或多列海报准确识别。
- `node check-ocr.cjs` 检查文本提取规则；已用生成的清晰中文测试图片跑通识别、核对及双日保存。尚未完成真实 iPhone 和用户订单/海报样本验证。

## 照片底海报修复

- 用用户提供的 AURA 海报复现了原版所有字段为空的问题。修复后采用整图、分区、自动浅色文字行与英文日期行补读；保留原图，不上传至识别服务。
- 浅色细字分离后增强笔画；混排日期和票价按主要字号分离。英文月份、跨行年份、多个非连续日期及 OCR 产生的空格／点号分隔都进入核对区。
- 已知艺人的中英文名称可匹配；场馆别名仅对有明确映射的场馆补全城市，界面提示核对。启德主场馆资料：https://www.kaitaksportspark.com.hk/venues-spaces/4 。没有把此海报的活动名称或日期预置进应用。
- 多轮结果逐轮提取；日期不一致时保留候选来源并取消自动勾选，不再用整轮置信度直接覆盖其他日期。多城市海报按站点核对。提供逐步进度、取消和超时处理。
- 规则回归包含实际原图的 OCR 输出。识别效果仍需对照原图，尚未完成真实 iPhone Safari 的性能与准确性验证。
- OCR 处理方式参考 Tesseract 官方文档：https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html 。

## 识别误填防护（2026-10-22）

- 针对用户结果截图中的异常括号标题，增加可疑名称检查；有不同完整名称时留空并保留候选。没有根据截图硬编码活动名称或日期。
- 日期规则排除带货币标记的价格，拒绝截断过长数字；不同识别分区不能拼接生成新的日期或标题。日期有分歧时，备注也不会自动消除分歧。
- 核对区显示日期来自哪轮识别；修改原文可重新提取。原始图片、识别原文和分轮结果都仅在当前设备处理。
